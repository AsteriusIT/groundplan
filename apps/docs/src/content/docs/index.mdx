This site answers two questions and deliberately no others: **how do I install
%PRODUCT%**, and **how do I use it**. If you are still deciding whether you want
it at all, the [product site](https://www.groundplan.qcs.ovh) is the better
read — it has the pitch; this one has the procedures.

%PRODUCT% turns Terraform and Kubernetes into living, interactive architecture
diagrams: a pull request is reviewed as a picture, and the documentation of your
default branch redraws itself on every merge.

## What it never asks for

The whole design follows from one rule: **we ingest data, not access.**
%PRODUCT% reads the plan JSON and the rendered manifests your own pipeline
already produces. Concretely, and with no exception anywhere in the product:

- it holds **no cloud credentials** — no subscription, no IAM role, no access
  key, nothing to rotate and nothing to revoke;
- it reads **no Terraform state backend** — when you want the picture of what
  really exists, the state is parsed and stripped
  [in the CLI, on your machine](/use/drift-and-reality/), and only the derived
  graph is sent;
- it runs **neither `terraform`, `helm` nor `kustomize`** — your pipeline
  renders, and we ingest the result.

Adoption is one pipeline step, and there is nothing left behind afterwards.
